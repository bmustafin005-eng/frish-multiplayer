# ФРИШ Multiplayer Test v0.4

Сетевая игровая версия: 1–4 человека в комнате, свободные места занимают боты.

Render:
- Build Command: `npm install`
- Start Command: `npm start`

v0.4:
- единое состояние партии хранится на сервере;
- чужие руки скрыты;
- раздающий/снимающий: снимает игрок справа от раздающего;
- снятие 7 секунд, затем автоматическое;
- светка видна всем;
- раздающий получает 15 карт, остальные 14;
- раздающий первым сбрасывает карту без добора;
- ход, колода и сброс синхронизируются;
- можно выкладывать базовые терцы;
- завершённый терец одинакового ранга (4 карты) помечается на захоронение и остаётся на столе полный круг; убирается при начале следующего хода игрока, который его забил;
- сервер не отправляет игроку карты соперников.

Это сетевой тестовый слой. Полный движок правил ФРИШ переносится поэтапно из основного прототипа.
