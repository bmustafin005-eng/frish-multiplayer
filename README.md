# ФРИШ Multiplayer Test

Первый сетевой каркас: хозяин создаёт комнату, получает код FRISH-XXXX, 1–3 человека подключаются по коду, свободные места при старте занимают боты.

## Запуск
1. Установить Node.js 18+.
2. В папке проекта: `npm install`
3. `npm start`
4. Открыть `http://localhost:3000`.

Для игры с людьми через интернет проект нужно разместить на публичном Node.js-хостинге. Этот билд проверяет комнату/подключения; полный игровой движок правил ФРИШ переносится следующим слоем на сервер.
